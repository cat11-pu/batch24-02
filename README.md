# GSB Bugfix Task
## 题面
接口签名校验现在形同虚设：参数顺序一变就验不过，空签名反而放行，时间戳不校验，重放也不拦。signature_guard.py 是核心，tests/test_signature_guard.py 15 个红。要修成参数规范化后签名稳定、空签名和空密钥明确拒绝、时间戳超出窗口拒绝、同一签名不能重放、比较用常量时间。修完 15 个测试后，还要保证 1000 组随机参数和签名下没有绕过，32 线程并发提交同一签名只能成功一次；不许改测试或硬编码测试参数。边界至少覆盖空签名、空密钥、过期时间戳、未来时间戳、重复参数键。

## 运行方式
```bash
python -m pytest tests -q
```
